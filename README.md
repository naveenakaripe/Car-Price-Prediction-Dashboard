# Car Price Prediction Dashboard

## Introduction
This project predicts used car prices using machine learning.

## Aim
To estimate car selling prices based on year, fuel type and mileage.

## Requirements
- Python
- Pandas
- Scikit-Learn
- Streamlit

## Procedure
1. Load dataset.
2. Clean data.
3. Train Random Forest Regression model.
4. Create Streamlit dashboard.
5. Predict car prices.

## Conclusion
The dashboard successfully predicts car prices and visualizes feature importance.
